## Як зробити нову партію
1. У content.py замінити список GP на нові 10 питань (для іншої гілки — змінити BRANCH: назва, теглайн, колір, бот).
2. Шрифти: папка fonts бота (або змінна NK_FONTS).
3. Запуск (Python 3 + Pillow, python-docx, ffmpeg):

```
python3 make_cards.py "ГП 31-40/1_ГП-31–40 картки і відео"
python3 make_video.py "ГП 31-40/1_ГП-31–40 картки і відео" "Мелодія бренду NK.wav"
python3 make_texts.py "ГП 31-40" 31-40 <дата>
```

Правила: текст у відео не правіше x=940 і не нижче y=1520 (безпечні зони Reels/TikTok); у курсиві PT Serif немає стрілок → ↑ — не вживати їх у примітках.
